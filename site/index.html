How it works

Nothing is installed into the programs Lody reads. It follows what they already write, the way you would read over their shoulder.

1

Follows the program

Lody knows when there's something worth hearing: a reply that's finished, or what a tool is doing while it works.

2

Translates only the prose

Code, paths, links and secrets stay on your computer. Only the sentences go to the translator.

3

Reads it aloud

Pick from free natural voices. Start something new and it stops, so it never talks over you.

Talk and listen, hands free

In the terminal, a conversation needs no keyboard and no screen: you speak, the AI works, Lody tells you what it did.

Speak · optional

Handy

Turns your voice into text in any program. Lody can install it and check that it suits your language.

Listen

Lody

Reads the answer aloud in your language, and waits while you speak.

Works with

Lody isn't only for AI. Each program it reads is one small module, so anyone can teach it another in a single file. Thai comes first; a new language is one file too.
